La API pública de Tartini permite integrar funcionalidades de inteligencia artificial y base de conocimiento a sistemas externos: chatbots, CRMs, aplicaciones web y más.

---

## URL base

Todas las solicitudes deben hacerse a:

```
https://api-talk.saninternet.com/v1
```

---

## Autenticación

Todas las solicitudes requieren una API key válida enviada en el header `Authorization`:

```
Authorization: Bearer pyp_live_SUA_API_KEY
```

<Note>
  Las API keys se generan en el [Dashboard](https://talk.saninternet.com) en **Configurações > API Keys** (Configuraciones > API Keys). Consulta la guía completa en [Autenticación](/es/concepts/authentication).
</Note>

## Formato de respuesta

Todas las respuestas se devuelven en JSON. En caso de error:

```json
{
  "statusCode": 401,
  "error": "Unauthorized",
  "message": "Invalid or expired API key"
}
```

---

## Códigos de estado

| Código | Descripción |
|--------|-----------|
| `200` | Éxito |
| `401` | API key ausente, inválida o expirada |
| `403` | Suscripción inactiva (`SubscriptionInactive`) |
| `422` | Error de validación en el cuerpo de la solicitud |
