La API de Tartini es el camino para que el sistema de tu empresa converse con la plataforma por su cuenta: un CRM, un e-commerce, un sistema de cobranza o cualquier aplicación tuya que necesite hablar con Tartini sin pasar por la pantalla.

---

## Cómo obtener acceso

El acceso a la API se habilita bajo solicitud. Para recibir la documentación técnica y las credenciales, contacta al equipo de Tartini por el canal de atención de tu cuenta. El equipo confirma lo que tu integración necesita y habilita el acceso.

<Note>
  La conexión vía API forma parte de los planes Scale y Enterprise. Dentro de Tartini, los tokens de acceso los genera y revoca el Administrador, en **Configurações > Integrações > Conexão via API** (Configuración > Integraciones > Conexión vía API).
</Note>

---

## Lo que ya existe sin la API

Antes de pedir acceso, vale la pena revisar si lo que necesitas ya está listo en la plataforma:

- **Webhooks**: Tartini avisa a tu sistema cada vez que se finaliza una atención, con los datos del contacto, el motivo del cierre y, si quieres, el resumen del Tino y el historial. Mira [Recibe eventos en tu sistema](/es/integracoes/webhooks).
- **Conectores**: el Tino consulta y actúa en tu sistema durante la conversación, mediante integraciones listas o un servidor MCP de tu empresa. Mira [Conecta herramientas externas a la IA](/es/integracoes/conectores).
- **Campañas por webhook**: tu sistema envía cada contacto que el Tino debe abordar. Mira [Dispara campañas por webhook o por mensaje recibido](/es/campanhas/webhook-e-inbound).
