La base no tiene color: papel claro y una tinta cálida, #14120F, que nunca es negro puro. Sobre ella entran dos señales, terracota para personas y cobalto para inteligencia artificial, y nada más.

---

## El principio

El cobalto es el color más protegido del sistema. Cuando se usa como color de enlace o de destacado, el cliente pierde la única referencia confiable para saber que está leyendo una máquina.

Verde, rojo y ámbar entran por significado: verde para completado, conectado y saludable; rojo para peligro real, como eliminar, salir, error de validación y canal fuera de línea; ámbar para pendiente que todavía no es error. Usar rojo como destacado gasta la única palabra que el sistema tiene para decir peligro.

El azul de SAN, #007BFF, queda fuera de la interfaz del producto: colisiona con el cobalto. Su lugar es el sello de procedencia.

---

## Proporción

La pantalla es casi toda neutra: cerca de 60% papel, 25% tinta, y el resto dividido entre las dos señales. Una pantalla mayoritariamente terracota o cobalto está mal aunque use los colores correctos.
