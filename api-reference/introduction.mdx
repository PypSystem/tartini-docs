A API do Tartini é o caminho para o sistema da sua empresa conversar com a plataforma por conta própria: um CRM, um e-commerce, um sistema de cobrança ou qualquer aplicação sua que precise falar com o Tartini sem passar pela tela.

---

## Como ter acesso

O acesso à API é liberado sob solicitação. Para receber a documentação técnica e as credenciais, entre em contato com o time do Tartini pelo canal de atendimento da sua conta. O time confirma o que a sua integração precisa e libera o acesso.

<Note>
  A Conexão via API faz parte dos planos Scale e Enterprise. Quem gera e revoga os tokens de acesso dentro do Tartini é o Administrador, em **Configurações > Integrações > Conexão via API**.
</Note>

---

## O que já existe sem a API

Antes de pedir acesso, vale conferir se o que você precisa já está pronto na plataforma:

- **Webhooks**: o Tartini avisa o seu sistema a cada atendimento finalizado, com os dados do contato, o motivo do encerramento e, se você quiser, o resumo do Tino e o histórico. Veja [Receba eventos no seu sistema](/integracoes/webhooks).
- **Conectores**: o Tino consulta e age no seu sistema durante a conversa, por integrações prontas ou por um servidor MCP da sua empresa. Veja [Conecte ferramentas externas à IA](/integracoes/conectores).
- **Campanhas por webhook**: o seu sistema envia cada contato que o Tino deve abordar. Veja [Dispare campanhas por webhook ou por mensagem recebida](/campanhas/webhook-e-inbound).
