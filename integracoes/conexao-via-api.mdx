Com um token de API, o seu sistema conversa diretamente com o Tartini, sem precisar de ninguém abrindo a tela.

<Note>Quem gera e revoga tokens: só o Administrador. Disponível no plano Scale.</Note>

---

## Para que serve

Um token de API dá ao seu sistema acesso à API pública do Tartini, com funcionalidades de inteligência artificial e busca na base de conhecimento. Os detalhes técnicos de uso da API ficam com quem desenvolve o seu sistema.

Onde fica: **Configurações > Canais > Conexão via API**.

<Note>
  Mantenha seus tokens em segurança e nunca os compartilhe. Quem tiver o token consegue acessar sua conta pela API, do mesmo jeito que você.
</Note>

---

## Um token por sistema

É possível criar mais de um token, um para cada sistema integrado, com um nome que identifica onde cada um é usado, como "Integração ERP".

Cada token é revogado de forma independente: revogar o de um sistema não afeta os demais.

---

## Gere um token

Por padrão, uma conta nova não tem nenhum token criado.

<Steps>
  <Step title="Abra a tela">Vá em **Configurações > Canais > Conexão via API**.</Step>
  <Step title="Comece um novo token">Clique em **Criar Token**.</Step>
  <Step title="Nomeie o token">Preencha **Nome do Token**, para identificar depois onde ele é usado, e opcionalmente uma **Descrição**.</Step>
  <Step title="Crie">Clique em **Criar Token**.</Step>
  <Step title="Copie e guarde">Clique em **Copiar** e guarde o token em local seguro.</Step>
</Steps>

{/* CAPTURA: images/integracoes/conexao-via-api-token-criado.png | alt: modal com o token de API gerado e o botão de copiar | olhar: o aviso de que o token só aparece essa vez */}

<Warning>
  O token só é exibido uma vez, no momento da criação. Se perder, não tem como recuperar: crie um novo e revogue o antigo.
</Warning>

---

## Acompanhe seus tokens

Cada token cadastrado mostra o nome, a descrição, quando foi criado e a última vez que foi usado, ou **Nunca**, se ainda não foi usado.

---

## Revogue um token

<Steps>
  <Step title="Abra a tela">Vá em **Configurações > Canais > Conexão via API**.</Step>
  <Step title="Exclua o token">Clique no ícone de lixeira no card do token.</Step>
  <Step title="Confirme">Clique em **Excluir**.</Step>
</Steps>

<Warning>
  Depois de revogado, o token deixa de funcionar e qualquer sistema que o usava perde o acesso.
  {/* CONFIRMAR: se a revogação tem efeito imediato ou pode haver atraso de propagação/cache */}
</Warning>

## Perguntas frequentes

<AccordionGroup>
  <Accordion title="Quem pode criar ou revogar tokens?">
  Só o Administrador.
  </Accordion>
  <Accordion title="Perdi o token antes de copiar. Como recupero?">
  Não é possível recuperar um token depois de fechar o modal. Crie um novo e revogue o antigo, se ele não estiver em uso.
  </Accordion>
  <Accordion title="Os tokens expiram sozinhos?">
  {/* CONFIRMAR: se os tokens de API têm expiração automática */}
  </Accordion>
  <Accordion title="Preciso de um token diferente para cada sistema que eu integrar?">
  Não. Você pode usar um único token em vários sistemas ou criar um para cada um. Tokens separados facilitam identificar onde cada um é usado e permitem revogar o acesso de um sistema sem afetar os outros.
  </Accordion>
</AccordionGroup>
